# Experiment configuration

The dissertation used Sentence and Token splitters at (512, 50), Sentence Window at 7 neighboring sentences, Semantic at (buffer 1, threshold 98), and Hierarchical at (2048, 1024, 512). These are historical settings, not newly executed results.

For each new experiment, record corpus manifest digest, benchmark version, language, parser version, embedding and generator model identifiers, retrieval settings, context budget, seed, software environment and run ID. Never overwrite paper-aligned outputs.
